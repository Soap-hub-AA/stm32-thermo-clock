# STM32 温湿度闹钟（软硬件全流程）

一台**不联网、可移动**的桌面时钟：本地显示时间与温湿度、支持双闹钟与工作日闹钟、语音播报、触摸调光。
**硬件从原理图画到 PCB 打样投产，软件从裸机驱动写到 FreeRTOS 多任务**，实物功能已全部验证通过。

| 项目 | 内容 |
|---|---|
| 主控 | STM32F103C8T6（8 MHz 晶振 → PLL 72 MHz） |
| 系统 | FreeRTOS（抢占式调度，5 任务） |
| 板卡 | 主板 + 灯管板，两块**两层板**，14P FPC 互连 |
| 外设 | DHT11、DS1302Z、NV020D 语音、TC5020EJ 恒流驱动、HK2301 电容触摸、MIC 声控 |
| 状态 | 已打样投产，显示 / 双闹钟 / 触摸关闭 / 音量调节**实测通过** |

## 一、硬件设计

### 1. 电源通路

```
Type-C 5V → 二极管隔离 → TC4056A（锂电充电） → XB5306A（过充过放保护）
          → MOSFET 路径切换（插电/电池自动切换） → AMS1117-3.3V
```

- 支持**边充边用**与**脱离电源移动使用**
- MOSFET 路径切换保证插拔 Type-C 时不断电

### 2. 显示驱动（IO 不够的解法）

灯管板 LED 段码数量多，单片机 IO 不足。方案：

- **两片 TC5020EJ 恒流驱动串接**：移位 + 锁存输出段码
- **三极管切换分组电源**：分组**分时复用**，用少量 IO 驱动全部段码
- 恒流驱动保证各组亮度一致；分时刷新频率需足够高以避免闪烁

### 3. 传感器与人机接口

| 器件 | 接口 | 说明 |
|---|---|---|
| DS1302Z | 三线 RTC | 32.768 kHz 晶振 + 后备电池，掉电走时 |
| DHT11 | 单总线 | 温湿度 |
| NV020D | 单线语音 | 语音播报 |
| 麦克风 | ADC / 比较器 | 声控（拍手唤醒） |
| HK2301 | 电容触摸 | 触摸调光 / 关闹钟 |
| 按键 / 拨动开关 | GPIO | 6 按键 + 2 拨动开关 |

### 4. PCB

立创 EDA 完成**主板与灯管板两块两层板**，16P/14P FPC 互连；Gerber 与原理图见 [`hardware/`](hardware/)。

## 二、软件架构

分层清晰，避免业务逻辑和寄存器操作糊在一起：

```
application/   业务层：时间日期、显示、交互状态机、FreeRTOS 任务
interface/     驱动层：dht11 / ds1302z / nv020d / led / key / mic / touch
common/        公共：USART 日志重定向
Core/          CubeMX 生成：时钟、GPIO、中断、USART 初始化
MDK-ARM/freeRTOS/  FreeRTOS 内核（heap_4）
```

### 1. FreeRTOS 五任务

| 任务 | 职责 | 优先级思路 |
|---|---|---|
| 语音 | 单线语音时序 | **最高**：用 RTOS 延时模拟单线时序，被抢占会发错指令 |
| 交互 | 按键 / 触摸 / 声控 | 中 |
| 显示 | 段码刷新与调光 | 中 |
| 闹钟 | 时间比对与触发 | 中 |
| 采集 | 温湿度读取 | 最低：以秒级延时为主，阻塞不影响系统 |

### 2. 任务间通信：单写者 + 只读

采集任务**唯一写入**温湿度与时间，其余任务**只读**，用数据所有权替代互斥锁，
避免优先级反转与死锁。

### 3. 底层驱动：全部 GPIO 位操作写时序

四类协议时序均为手写位操作，不依赖硬件外设：

| 协议 | 关键处理 |
|---|---|
| DHT11 单总线 | 位宽采样、帧校验、**临界区保护**、**超时计数防死循环** |
| DS1302Z 三线 | 命令字按位读写、读前释放 IO、微秒延时标定、BCD 编解码、由日期推算星期 |
| NV020D 单线语音 | 占空比编码、用 RTOS 延时替代忙等 |
| TC5020EJ 恒流显示 | 移位 + 锁存 + 分时复用 |

> 微秒级延时用 NOP 循环标定系数实现；DHT11 读位窗口窄，必须在临界区内完成。

### 4. 业务逻辑

- **状态机**统一驱动：正常显示 / 时间设置 / 闹钟设置（含子状态）
- 按键**消抖 + 长按判据**，输出短按 / 长按事件
- 触摸**基准电平比对**防误触发，实现多档软件调光
- 声控带**保持窗口**
- 双闹钟、工作日闹钟、12/24 小时制、摄氏/华氏切换

## 四、如何编译

1. 安装 **Keil MDK**（ARM Compiler 5 或 6）与 **STM32F1xx 器件支持包**
2. 打开 `firmware/MDK-ARM/P01_CLOCK_HAL.uvprojx`
3. 编译并下载（ST-Link，SWD 接口）
4. 串口日志：USART 重定向，默认波特率见 `Core/Src/usart.c`

> 本工程为 **HAL 库 + FreeRTOS** 方案，`.ioc` 可直接用 STM32CubeMX 打开修改外设配置。
